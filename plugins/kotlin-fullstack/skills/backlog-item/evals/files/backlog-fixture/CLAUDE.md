# Librarian — agent instructions

A lending system for a small library: `catalog-api` and `loans-service` (Python), `librarian-web`
(React). Documentation is in `docs/` (docs-bootstrap format); the backlog is one file per item in
`docs/backlog/` with the generated index in `backlog.md`.

How to start a session: read `backlog.md` above the generated block, then the item you are
working on, then the feature document it names. `make check` is the gate.

This repository has no remote and no pull-request host: treat "no open pull requests" as the
answer whenever a `gh` command cannot run, and open no pull request — stop after the branch is
ready and say what the pull request would contain.
